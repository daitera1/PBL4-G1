\hypertarget{class_overview_class_flow_sec}{}\doxysubsection{\texorpdfstring{Processing Flow}{Processing Flow}}\label{class_overview_class_flow_sec}

\begin{DoxyEnumerate}
\item {\bfseries{Main\+Alpha\+Blender}} starts the program and creates a {\bfseries{Config\+Reader}}.
\item {\bfseries{Config\+Reader}} loads all projector and image parameters.
\item {\bfseries{Image\+Read\+Write}} reads the source image.
\item {\bfseries{Crop\+Image}} cuts the image into the left and right parts.
\item {\bfseries{Calculate\+Overlap}} determines the overlap region for this projector side.
\item {\bfseries{Mask\+Creator}} builds the gamma-\/based blending mask.
\item {\bfseries{Main\+Alpha\+Blender}} applies the mask and displays the result in full screen.
