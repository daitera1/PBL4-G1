Individual Week 1 requirements

  • Tasks 1–3: record your own experience, confirm resources are downloaded, and check Astah, M+ and Doxygen work.
  • Task 4: make your own three-class diagram, with 2–3 attributes and 2–3 methods per class, a class name containing your name, appropriate links, and at least one method per class with 1–2 input arguments. Save the Astah file.
  • Task 5 and the two activities both labelled Task 6: export C++, C# and Java; import the Java back into a diagram; generate Python with M+. Keep the requested code/diagram screenshots.
  • Task 7: investigate CodingRule.cpp and CodingRule.h. Tasks 8–9: generate HTML for GoodCodingExampleCPP, then comment and document your own generated Python code. Paste the required first-page screenshots into your individual form.
