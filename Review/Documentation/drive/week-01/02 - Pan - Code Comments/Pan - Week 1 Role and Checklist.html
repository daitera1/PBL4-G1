Read first

Your team checklist

  • Write a short list of useful coding conventions from the provided samples: meaningful names, indentation, spaces and consistent comments. These samples teach C++ style; keep Python indentation valid.
  • Read the Python section of Doxygen’s Documenting the code guide. Agree one style with Monika. A useful comment explains purpose, inputs, output and any important restriction.
  • Use your own Astah-generated Python code for the individual assignment. For the team trial, select a small class or method and add accurate Doxygen comments. Ask its developer about behaviour you cannot confirm.
  • Send the team trial source or repository link to Monika. Generate the HTML together and check that the intended descriptions appear. Record anything Doxygen does not recognise.
  • Write a short comment checklist that developers can follow. Ask Haruho or Daisuke to review one example for accuracy, then let Monika check the generated page.
