G1-2 Documentation Working Draft

Team writing space. The prompts below guide drafting; they are not completed project findings. Update each section here and track its owner, reviewer and deadline in Jira.

Project overview

Owner: Sousuke. Technical reviewer: Haruho (proposed).
Explain the problem, intended users and project goal. Describe the input and expected output. Separate agreed requirements from ideas that still need discussion.

Design and UML

Owner: Sousuke. UML contributor: Daisuke. Technical reviewer: Haruho (proposed).
Insert the current UML export and explain the main components, their responsibilities and data flow. Explain where alignment and blending happen. Record the matching code version so the diagram and implementation can be checked together.

Installation and running instructions

Owner: Bien. Test reader: a teammate who did not write the instructions.
List the supported operating system, required software and versions, project download location, installation steps, commands to run, sample input and expected output. Have the test reader try the instructions and record any missing steps.

Tests, results and limitations

Owner: Bien. Contributors: Hanz and Marcus.
For each test, record its purpose, code version, input, settings, expected result, actual result and evidence filename. Add a caption explaining what each screenshot shows. Record failures and limitations as well as successful results.

Code comments and API documentation

Code-comment owner: Pan. Doxygen owner: Monika.
Keep the actual comments in the code repository. Use this section to record documentation gaps, the Doxygen generation instructions, the code version checked and the location of the generated output. Developers review explanations of function behaviour.

Questions and review decisions

Use comments beside the relevant passage for detailed review. Record agreed changes here with the responsible person and related Jira task. Sariga captures decisions that affect the wider team.

Ready for team review

Check that the overview matches the implemented project, UML matches the code, setup steps have been tried, results have evidence, Doxygen output opens correctly, links work and all required course deliverables are included.
