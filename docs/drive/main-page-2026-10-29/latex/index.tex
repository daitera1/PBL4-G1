This is the User Manual for the Multi-\/\+Projector Alpha Blending application. The program displays one image across two adjacent projectors and applies a gamma-\/corrected alpha mask to the overlapping region, so that the final projected image looks like one large, seamless picture. The application reads its settings (image path, projector distance, gamma, etc.) from a configuration file and uses Open\+CV and Num\+Py for image processing.

Run the following command:

{\bfseries{Step 2: Configure the settings}}

Open {\ttfamily config.\+json} and adjust the values if needed:
\begin{DoxyItemize}
\item {\bfseries{image\+\_\+name}}: path to the image you want to project
\item {\bfseries{side}}: {\ttfamily left} or {\ttfamily right}, the position of this projector
\item {\bfseries{distance\+\_\+between\+\_\+projectors}}: distance between the two projectors (cm)
\item {\bfseries{projected\+\_\+image\+\_\+width}}: width of one projector\textquotesingle{}s image (cm)
\item {\bfseries{gamma}}: gamma value used when creating the mask
\end{DoxyItemize}

\hypertarget{index_arch_sec}{}\doxysection{\texorpdfstring{4. System Architecture}{4. System Architecture}}\label{index_arch_sec}
The application consists of two main components:


\begin{DoxyEnumerate}
\item {\bfseries{Main\+Alpha\+Blender}}: the main controller class. It loads the image, calculates the overlap region and applies the alpha mask.
\item {\bfseries{Config\+Reader}}: a helper class that reads {\ttfamily config.\+json} and provides getter methods for the projector parameters.
\end{DoxyEnumerate}\hypertarget{index_math_sec}{}\doxysection{\texorpdfstring{5. Mathematical Foundation}{5. Mathematical Foundation}}\label{index_math_sec}
Projectors do not have a linear luminance response, so simple linear blending produces bright or dark bands in the overlap region. Gamma correction is used to compensate for this:

\[  M(x) = B(x)^{1/\gamma}
\]

where:
\begin{DoxyItemize}
\item $M(x)$ is the calculated mask value,
\item $B(x)$ is the linear ramp value (0 to 1),
\item $\gamma$ is the gamma value (typically 2.\+2 to 2.\+4).
\end{DoxyItemize}\hypertarget{index_vis_sec}{}\doxysection{\texorpdfstring{6. Visualization of the Blending Process}{6. Visualization of the Blending Process}}\label{index_vis_sec}
\hypertarget{index_before_sec}{}\doxysubsection{\texorpdfstring{Before Mask Application}{Before Mask Application}}\label{index_before_sec}
The raw left and right projector inputs. Without the mask, the overlap region appears brighter than the rest of the image.

 \hypertarget{index_after_sec}{}\doxysubsection{\texorpdfstring{After Mask Application}{After Mask Application}}\label{index_after_sec}
After applying the gamma-\/corrected alpha mask, the brightness in the overlap region matches the rest of the image.
