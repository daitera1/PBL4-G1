Class Overview

This page gives an overview of all classes in the Alpha Blender system and explains how they work together.

Click a class name to open its detailed reference page.

Class List

Class File Responsibility
MainAlphaBlender main_alpha_blender.py Entry point. Controls the whole pipeline and displays the final image.
ConfigReader config_reader.py Reads projector and image settings (width, distance, overlap, gamma, side).
ImageReadWrite image_read_write.py Loads the source image from disk as an OpenCV Mat.
CropImage crop_image.py Splits the source image into left and right parts for each projector.
CalculateOverlap calculate_overlap.py Calculates the overlap width and the gamma-corrected alpha values.
MaskCreator mask_creator.py Creates the gradient mask applied to the overlap region.

Processing Flow

  1. MainAlphaBlender starts the program and creates a ConfigReader.
  2. ConfigReader loads all projector and image parameters.
  3. ImageReadWrite reads the source image.
  4. CropImage cuts the image into the left and right parts.
  5. CalculateOverlap determines the overlap region for this projector side.
  6. MaskCreator builds the gamma-based blending mask.
  7. MainAlphaBlender applies the mask and displays the result in full screen.

Class Details

MainAlphaBlender

The controller of the system. It owns the ConfigReader instance and calls the other classes in order.

  • Method: display()

ConfigReader

A helper class that stores every configuration value and provides getter methods for them.

  • Main methods: getProjectedImageWidth(), getDistanceBetweenProjector(), getImageWidth(), getImageHeight(), getImageName(), getSide(), getGamma()

ImageReadWrite

Reads the image file given by img_filename and keeps it in memory.

  • Method: getImage()

CropImage

Produces img_left and img_right, the two images sent to the projectors.

  • Method: crop()

CalculateOverlap

Uses the projector side and overlap width to compute the alpha ramp:

  • Method: alphaGamma()

MaskCreator

Generates the gradient mask from the gamma value and the overlap width in pixels.

  • Method: createMask()
