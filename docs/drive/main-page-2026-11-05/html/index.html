Alpha Blending Multi-Projector Documentation

1. Introduction

This is the User Manual for the Multi-Projector Alpha Blending application. The program displays one image across two adjacent projectors and applies a gamma-corrected alpha mask to the overlapping region, so that the final projected image looks like one large, seamless picture. The application reads its settings (image path, projector distance, gamma, etc.) from a configuration file and uses OpenCV and NumPy for image processing.

2. System Requirements

  • Operating System: Windows 10 / 11 (tested)
  • Python: 3.9 or later
  • Required Python Libraries:
    1. numpy
    2. opencv-python
  • Hardware: two projectors placed side by side with an overlapping area

3. Setup

Step 1: Install required packages

Run the following command:

pip install -r requirements.txt

Step 2: Configure the settings

Open config.json and adjust the values if needed:

  • image_name: path to the image you want to project
  • side: left or right, the position of this projector
  • distance_between_projectors: distance between the two projectors (cm)
  • projected_image_width: width of one projector's image (cm)
  • gamma: gamma value used when creating the mask

Step 3: Run the program

python main_alpha_blender.py

4. System Architecture

The application consists of two main components:

  1. MainAlphaBlender: the main controller class. It loads the image, calculates the overlap region and applies the alpha mask.
  2. ConfigReader: a helper class that reads config.json and provides getter methods for the projector parameters.

5. Mathematical Foundation

Projectors do not have a linear luminance response, so simple linear blending produces bright or dark bands in the overlap region. Gamma correction is used to compensate for this:

\[ M(x) = B(x)^{1/\gamma} \]

where:

  • \(M(x)\) is the calculated mask value,
  • \(B(x)\) is the linear ramp value (0 to 1),
  • \(\gamma\) is the gamma value (typically 2.2 to 2.4).

7. Usage Notes

  • Make sure both projectors use the same resolution (e.g. 1920x1080).
  • If a visible seam remains, adjust the gamma value in config.json.
  • Press any key or close the window to exit the program.
