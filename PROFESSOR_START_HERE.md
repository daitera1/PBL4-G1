# Professor — start here

**PBL4 Group 1 · Multi-projector image blending · 12 November 2026**

The project combines two projector images into one wide image. Gamma correction adjusts brightness where the images overlap. The presentation contains the team's reported results and photographs.

## Download and open everything

1. [Download the complete ZIP](https://github.com/daitera1/PBL4-G1/archive/refs/heads/main.zip).
2. **Extract the whole ZIP** into one folder.
3. Double-click **START_HERE.html**. It links to the presentation, final manual and formatted review pages.

Keep all folders together. On GitHub, Markdown pages and images display directly. For the complete Doxygen manual, use the extracted ZIP: GitHub displays HTML source rather than the rendered manual. PowerPoint, Word, Excel and Astah files need a compatible app; the presentation PDF and UML PNG can be viewed without those apps.
