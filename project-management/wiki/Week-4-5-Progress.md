# Week 4–5: Project Progress and Team Updates

## 1. Overview

During Weeks 4 and 5, the team continued working on the image blending system, project documentation, and task management. The main focus was on combining the existing code, improving the software structure, updating UML diagrams, and preparing documentation.

## 2. Development Team Progress

The development team made progress in organizing and improving the image blending system.

- Combined the separate left and right image blending scripts into a single `main.py` file.
- Created two versions of the blending system, with and without gamma correction, for comparison.
- Moved configuration settings into a separate `config.py` file, which was later changed to `config.json`.
- Introduced `ConfigReader` to read the configuration settings.
- Organized the Python code into separate files corresponding to the UML classes.
- Set up the PBL4 GitHub repository and completed the initial commit.
- Continued testing image resizing, grayscale conversion, and required libraries.

## 3. Documentation Team Progress

The documentation team worked on preparing and improving the project's technical documentation.

- Established a common code comment format for documentation.
- Created the first draft of the Doxygen main page.
- Added descriptions of the project and its main components.
- Included class information and UML diagrams in the documentation.
- Discussed the documentation with the professor and made improvements based on the feedback.
- Continued refining the main page and organizing supporting information.

Some documentation sections depend on the completion of the development system.

## 4. Project Management Progress

The project management team continued coordinating tasks and monitoring progress.

- Organized team discussions and checked progress across different groups.
- Created and assigned tasks using Jira.
- Established schedules and deadlines for project activities.
- Reviewed completed and remaining tasks.
- Continued organizing the Confluence wiki to record project updates and team progress.

## 5. Challenges

- Finding suitable images for projector alignment and blending.
- Resolving image splitting and blending issues.
- Keeping the software implementation and UML diagrams consistent.
- Completing documentation sections that depend on the final system.
- Coordinating updates between different teams.

## 6. Next Steps

- Continue testing and improving the image blending system.
- Compare the results of blending with and without gamma correction.
- Ensure the UML diagrams match the updated Python code.
- Continue refining the Doxygen documentation.
- Complete the remaining setup instructions and results documentation.
- Update Jira tasks and maintain project progress records in Confluence.

## 7. Summary

During Weeks 4 and 5, the team made progress in software development, documentation, and project organization. The development team improved the structure of the image blending system, while the documentation team updated the Doxygen pages and UML information. The project management team continued tracking tasks and maintaining coordination between groups.
